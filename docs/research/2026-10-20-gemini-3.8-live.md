## Model
- ID `gemini-3.8-live` (GA 2026-09-24). Regions: `us`, `eu` multi-region, `us-central1`. 128K in / 64K out.
- Not supported: context caching, structured output, thinking config. `-extended-thinking` variant: Gemini API only (unverified on Vertex).
- Always-on affective dialog + proactive audio — do not send `proactivity` / `enable_affective_dialog` (error).
- Barge-in waits until user finishes. Async function calls by default (`SILENT` / `WHEN_IDLE` / `INTERRUPT`).
- New: `media_resolution`, `custom_vocabulary` in transcription config. Default turn coverage includes all video.
- Session: 10-min connection (resumption handles it), audio+video ≈ 2 min without compression.

## Billing
- No caching on Live. Every turn re-bills the whole context window. Cost scales with turn count × context size.
- Rates (Gemini API; Vertex unconfirmed): text in $0.75, audio in $3, image in $1, text out $4.50, audio out $12 per 1M.
- Estimate per 40-min session: audio-only $5–6, +1fps screen $8–10, + timer turns up to $15–25. Optimized $2–4.

## Cost levers (priority)
1. Stop the 15-s timer packets (≈160 extra turns). Use a `get_interview_clock()` tool + 3–4 milestone cues.
2. Lower compression: trigger ≈ 24–32K, target ≈ 12–16K; keep a short text design summary so memory survives.
3. Send screen frames only on change (+ one at end of candidate turn).
4. Test `media_resolution=LOW`, `TURN_INCLUDES_ONLY_ACTIVITY`.
5. Short system prompt (≤1,200 words); scoring rubrics belong to insights.
6. Log `usage_metadata` per turn.

## VAD
- Candidates pause to think: `silence_duration_ms` ≈ 1000–1500, low end-of-speech sensitivity (tune by test).

## Persona rules (prompt-ready)
1. Named senior engineer running a 40-min LLD round; evaluating, not tutoring.
2. 1–2 spoken sentences per turn; one question at a time.
3. Let the candidate drive; sparse backchannels ("mm-hm", "okay").
4. No generic praise; acknowledge specifics.
5. Don't correct immediately; probe later with a neutral question.
6. Hints only when stuck/asked: rephrase → narrow → name concept.
7. Never explain the solution or lecture; turn questions back.
8. Reference on-screen items by name; never mention screenshots/frames.
9. Natural spoken English, contractions; no lists aloud, no "Certainly!".
10. Let silence happen; check in only after a long pause.
11. Pace with natural transitions; mention time only at milestone cues.
12. Yield on interruption.
13. Push back on choices; accept reasonable justification.
14. Stay in character; never mention AI, prompts, scores, rubric.
15. Last 2 min: one-sentence impression (no score), invite questions, goodbye.
